## 一、这是什么

一个面向 Claude Code / Claude API 的 **Skill 包**，包含：

- **完整的业务底稿**（课程点位、客群、合作方、企业数据）
- **两套子模块**（公众号图文 + 视频号短视频简介），各有专属任务说明书、风格参考库、文案库
- **精选范例**（按文体 / 客群风格拆解结构套路）
- **硬性规则与品牌资产速查**（避免虚构、合规、品牌调性统一）

把整个 skill 放进 Claude 后，AI 即可按「渠道分支」自动判断公众号 vs 视频号，按需加载 references，输出真实可查、风格统一的玉柴研学文案。

## 三、渠道说明

| 渠道 | 适用内容 | 核心交付物 |
|---|---|---|
| **公众号** | 微信订阅号图文（订阅号「玉柴研学」） | 主标题 + 摘要 + 正文 + 标签（2~5 个）+ 配图提示词 |
| **视频号** | 微信视频号短视频简介 | 短标题 + 简介（60~120 字）+ 标签（恰好 15 个） |

两渠道共用业务底稿，但风格、任务说明书、文案库各自独立，AI 会按用户表述自动分支。

## 四、文档规范

**所有文档均使用 Markdown 编写**，无 .docx / .txt / .py 等其他格式。理由：

- 文本可读、AI 可直接读写、二进制无歧义
- 版本控制友好（diff 清晰）
- 风格参考库、任务说明书、文案集三类内容采用「主数据 Markdown + 按字段结构化」组织

## 五、如何使用

### 在 Claude Code 中

将 `ycyx-artical/` 目录放入 Claude Code 的 skills 加载路径（如 `~/.claude/skills/ycyx-artical/`），重启 Claude Code 后，AI 在收到「写一篇玉柴研学……」类请求时会自动激活本 skill。

### 在自定义 AI 智能体中

1. 打开 `SKILL.md`，将「完整提示词」区域（即 SKILL.md 正文）复制到智能体的系统提示词
2. 确保智能体能访问 `references/` 下的文档
3. 启动会话后，AI 自动按「渠道分支判断 → 加载 references → 生成草稿 → 写入文案库」流程运作

## 六、核心硬性规则（节选）

- **不虚构**：课程、点位、人物、机构、数据以业务简介与文案集历史为准
- **职业规划内容只面向高中学段**
- **不贩卖焦虑**；不用绝对化违禁词
- **主体名称按用户当次指定自适应**
- **不擅自新增子栏目或改变交付格式**

完整规则见 `SKILL.md` 第五节 与各子模块「任务说明书」。

## 七、迭代与维护

| 场景 | 改哪里 |
|---|---|
| 业务有变化（新课程/新合作方/新数据） | `references/业务简介.md` + 对应子模块文案集 |
| 风格有沉淀（新句式/新标签组合） | 对应子模块「风格参考库」的精选范例节 |
| 规则有迭代（新增硬性规则） | 对应子模块「任务说明书」+ `SKILL.md` 核心规则节 |
