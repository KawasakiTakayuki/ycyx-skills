## 一、品牌视觉基础（配色与字体）

> 依据玉柴集团官方品牌色「中国红 + 世界蓝」（红色代表激情与中国，蓝色代表科技与世界）。

**主色板**
| 色名 | 色值 | 用途 |
|---|---|---|
| 玉柴红 | `#C8102E` | 主色：按钮、标题强调、品牌元素 |
| 世界蓝 | `#0057B8` | 次主色：科技元素、渐变底 |
| 金属银灰 | `#A7A9AC` | 机械结构、关节、边框 |
| 能量暖橙 | `#FF8C1A` | 点缀：能量、火花、按钮高亮 |
| 奶白 | `#F7F3EC` | 背景、留白 |
| 深墨 | `#2B2B2B` | 正文文字 |

**配色比例**：红 40% / 蓝 30% / 灰白 25% / 橙 5%。红蓝为品牌识别色，画面中二者至少出现其一。

**字体**（海报/封面排版）
- 标题：思源黑体 Heavy / 阿里巴巴普惠体 Bold，可加"工业斜切"装饰。
- 正文：思源黑体 Regular，行距 1.6 以上。
- 数字/数据：加粗放大，可使用等宽感强的字体突出（如 1200万台、180+ 国家）。

## 二、海报与封面版式规范

| 场景 | 尺寸/比例 | 排版要点 |
|---|---|---|
| 公众号头条封面 | 900×383（约 2.35:1） | 左侧 2/3 实拍图（黑灯工厂/科技馆），右侧 1/3 放吉祥物＋标题区 |
| 次条封面/分享卡片 | 1:1（200×200+） | 吉祥物居中偏上，标题在下 1/3，四周留白安全区 |
| 文中插画 | 横版 16:9 | 与正文段落错开，吉祥物点缀，不抢文字 |
| 活动海报（朋友圈） | 3:4 竖版 | 标题上 1/3，核心卖点中段（3~4 条要点），吉祥物＋行动号召下 1/3 |
| 手机海报 | 9:16 | 同上，信息更精简 |

**通用排版规则**
- 四周保留 10% 安全区，文字、吉祥物不贴边。
- 标题使用 玉柴红/深墨 大字，关键数字加粗放大；背景优先用 奶白/深墨 高对比。
- 行动号召按钮（预约/报名/关注）统一 玉柴红底白字，放画面右下角。
- 一图一主信息：插画/海报只突出一个核心信息，不堆砌。

## 四、工作流衔接

1. 设计公众号封面、文中插画与海报时，配色与字体遵循「一、品牌视觉基础」，版式遵循「二、海报与封面版式规范」。

3. 成品图归档，后续同题材直接复用风格与模板，减少重复设计成本。
