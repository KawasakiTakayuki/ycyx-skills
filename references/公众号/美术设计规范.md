# 玉柴研学公众号美术设计规范

> 前置文档④：为公众号封面、文中插画、海报设计而设。
> 官方 IP 吉祥物形象已确定（玉柴三宝：团团 / 新新 / 当当），详见「三、美术角色设定」。

---

## 一、品牌视觉基础（配色与字体）

> 依据玉柴集团官方品牌色「中国红 + 世界蓝」（红色代表激情与中国，蓝色代表科技与世界）。

**主色板**
| 色名 | 色值 | 用途 |
|---|---|---|
| 玉柴红 | `#C8102E` | 主色：按钮、标题强调、品牌元素 |
| 世界蓝 | `#0057B8` | 次主色：科技元素、渐变底 |
| 金属银灰 | `#A7A9AC` | 机械结构、关节、边框 |
| 能量暖橙 | `#FF8C1A` | 点缀：能量、火花、按钮高亮 |
| 奶白 | `#F7F3EC` | 背景、留白 |
| 深墨 | `#2B2B2B` | 正文文字 |

**配色比例**：红 40% / 蓝 30% / 灰白 25% / 橙 5%。红蓝为品牌识别色，画面中二者至少出现其一。

**字体**（海报/封面排版）
- 标题：思源黑体 Heavy / 阿里巴巴普惠体 Bold，可加"工业斜切"装饰。
- 正文：思源黑体 Regular，行距 1.6 以上。
- 数字/数据：加粗放大，可使用等宽感强的字体突出（如 1200万台、180+ 国家）。

## 二、海报与封面版式规范

| 场景 | 尺寸/比例 | 排版要点 |
|---|---|---|
| 公众号头条封面 | 900×383（约 2.35:1） | 左侧 2/3 实拍图（黑灯工厂/科技馆），右侧 1/3 放吉祥物＋标题区 |
| 次条封面/分享卡片 | 1:1（200×200+） | 吉祥物居中偏上，标题在下 1/3，四周留白安全区 |
| 文中插画 | 横版 16:9 | 与正文段落错开，吉祥物点缀，不抢文字 |
| 活动海报（朋友圈） | 3:4 竖版 | 标题上 1/3，核心卖点中段（3~4 条要点），吉祥物＋行动号召下 1/3 |
| 手机海报 | 9:16 | 同上，信息更精简 |

**通用排版规则**
- 四周保留 10% 安全区，文字、吉祥物不贴边。
- 标题使用 玉柴红/深墨 大字，关键数字加粗放大；背景优先用 奶白/深墨 高对比。
- 行动号召按钮（预约/报名/关注）统一 玉柴红底白字，放画面右下角。
- 一图一主信息：插画/海报只突出一个核心信息，不堆砌。

## 三、美术角色设定（玉柴三宝 IP）

> 依据《玉柴集团吉祥物设计稿.jpg》官方设定。三只 Q 版小牛组成「玉柴三宝」IP，分别代表团结自强、开放创新、务实担当的企业精神。
> 角色选定参考：《玉柴集团企业精神》→ 团团 = 团结自强；新新 = 开放创新；当当 = 务实担当。

### 3.0 三宝总览

| 角色 | 江湖名号 | 寓意 | 性格 | 头身比 |
|---|---|---|---|---|
| **团团** | 电钻神功 | 团结自强 | 可爱呆萌，时刻准备开始战斗 | 大头 Q 版（约 1:1.5） |
| **新新** | 神牛摆尾 | 开放创新 | 性格开朗，侃侃而谈，热情善良 | 大头 Q 版（约 1:1.5） |
| **当当** | 闷声憋大招 | 务实担当 | 勤勤恳恳憨厚老实，不鸣则已一鸣惊人 | 大头 Q 版（约 1:1.5） |

**配色基线**：所有三宝均采用「玉柴红 `#C8102E` + 世界蓝 `#0057B8`」品牌色识别组合；皮肤为米色暖肤，腮红为浅粉红。

---

### 3.1 团团（电钻神功 · 团结自强）

**造型细节**
- **头部**：米色小牛头，戴**红色安全帽**（帽檐前有玉柴「YC」白色 logo）；头两侧各一支**银色螺旋钻头牛角**（电钻意象）。
- **五官**：圆润大眼（蓝色虹膜 + 白色高光），黑色细眉，红色腮红，闭合微笑嘴。
- **服饰**：**蓝色工装背带裤**（胸前有两个带纽扣方形口袋，膝盖处有红蓝拼色补丁），白色内衬 T 恤领口露出。
- **手脚**：白色手套，黑色圆头皮鞋；尾端保留小牛短尾。
- **姿态默认**：双手叉腰 / 单手敬礼 / 双手握拳。

**AI 生图基础角色卡（统一前缀）**
```
玉柴吉祥物「团团」Q 版小牛，戴红色安全帽（带白色玉柴 YC logo），头两侧银色螺旋钻头牛角，
蓝色工装背带裤，米色皮肤，蓝色大眼睛，红润腮红，大头身比约 1:1.5，可爱呆萌气质；
正面半身站姿，纯色背景，正面光。
```

**适用场景**：研学启动仪式、招募海报、节日主题封面、安全/团结主题内容。

---

### 3.2 新新（神牛摆尾 · 开放创新）

**造型细节**
- **头部**：**黄色**小牛头，棕色头发刘海（前额有一缕翘起的棕色呆毛），**蓝色大眼睛**（蓝色虹膜 + 白色高光），红色腮红，张嘴微笑露小白舌。
- **服饰**：**深灰色西装外套** + 白色衬衫 + **黑色小领结**，胸口绣有白色玉柴「YC」logo。
- **手脚**：白色手套（右手举起比 OK / 挥手），黑色圆头皮鞋；保留小牛细长尾巴（神牛摆尾意象）。
- **姿态默认**：挥手致意 / 比 OK / 拍胸脯。

**AI 生图基础角色卡（统一前缀）**
```
玉柴吉祥物「新新」Q 版小牛，黄色毛色，棕色刘海翘毛，蓝色大眼睛，红润腮红，张嘴微笑，
深灰西装外套 + 白衬衫 + 黑色小领结，胸口白色玉柴 YC logo，白手套，
大头身比约 1:1.5，开朗热情气质；正面半身站姿，纯色背景，正面光。
```

**适用场景**：签约仪式、对外合作、企业家/考察团、新品发布、创新主题内容。

---

### 3.3 当当（闷声憋大招 · 务实担当）

**造型细节**
- **头部**：**棕黄色**小牛头（比新新更深一度），棕色头发，**圆眼眯眼**（小眼睛或闭眼笑的神情），红润大腮红，张嘴微笑。
- **服饰**：**蓝色工装背带裤**（胸前两个方形口袋，膝盖处蓝红拼色补丁），内搭**白色长袖**，**红色三角巾**（围在领口，巾面带白色玉柴「YC」logo）。
- **手脚**：白色手套，黑色圆头皮鞋；保留小牛短尾。
- **姿态默认**：双手背后 / 双手握工具 / 单手拍胸脯。

**AI 生图基础角色卡（统一前缀）**
```
玉柴吉祥物「当当」Q 版小牛，棕黄色毛色，棕色头发，圆眼眯眼笑意，红润大腮红，
蓝色工装背带裤 + 白色长袖 + 红色三角巾（巾面白色玉柴 YC logo），白手套，
大头身比约 1:1.5，憨厚老实气质；正面半身站姿，纯色背景，正面光。
```

**适用场景**：大国工匠主题、生产车间/黑灯工厂实拍合影、教师培训、技术培训、匠心主题内容。

---

### 3.4 三宝选用指引

| 内容主题 | 主用角色 | 搭配 |
|---|---|---|
| 招募/海报/封面 | **新新**（开朗外向，吸引点击） | 可叠加团团做点缀 |
| 车间/工匠/技术 | **当当**（务实担当气质契合） | 配合生产实拍 |
| 安全/团结/家庭 | **团团**（可爱呆萌，亲和力强） | 配合家庭/亲子场景 |
| 三角色同框 | **三宝并列**（建立品牌 IP 一致性） | 用于品牌主视觉、年度回顾、重大节点 |
| 节日祝福 | 按节日气质：儿童节→团团；劳动节→当当；创新/合作类→新新 | 单角色即可 |

> 角色一致性原则：同一篇文章内若多次出现吉祥物，**全篇使用同一角色**，避免三角色混搭造成视觉混乱（除特别主题外）。

---

### 3.5 AI 生图使用规范

1. **永远使用上方角色卡作为前缀**：每次生图都先贴「玉柴吉祥物「XX」Q 版小牛……」描述锁定造型，避免模型自由发挥导致形象漂移。
2. **场景模板**：在角色卡后追加场景描述，如「在玉柴科技馆展厅内」「与孩子手拉手合影」「手捧发动机模型」等。
3. **风格统一**：画面风格保持「明亮、可爱、Q 版、平面感强」，避免写实风或 3D 风破坏品牌一致性。
4. **配色约束**：背景色用「奶白 `#F7F3EC`」或「世界蓝 `#0057B8`」单色背景，保证品牌识别。
5. **禁止随意增减元素**：头盔、领巾、工装等关键标识不可缺失；不要给角色添加照片中没有的配件。

## 四、工作流衔接

1. 设计公众号封面、文中插画与海报时，配色与字体遵循「一、品牌视觉基础」，版式遵循「二、海报与封面版式规范」。
2. 出图后在排版环节（如稿定/Canva/设计工具）添加文字标题、按钮与品牌标识。
3. 成品图归档，后续同题材直接复用风格与模板，减少重复设计成本。
4. 角色造型按「三、美术角色设定」执行，三宝角色卡为唯一来源；图片素材以《玉柴集团吉祥物设计稿.jpg》为基准。
