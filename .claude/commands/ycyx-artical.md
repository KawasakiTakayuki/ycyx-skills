# /ycyx-artical · 玉柴研学文旅新媒体文案

**任务参数**：`$ARGUMENTS`

> 使用本命令前，请确认 `ycyx-artical` skill 已部署：
> - 仓库：`https://github.com/KawasakiTakayuki/ycyx-skills`
> - 本地路径：`skills/ycyx-artical/`
> - SKILL.md：`skills/ycyx-artical/SKILL.md`

## 执行步骤

### 1. 加载 Skill

读取 `skills/ycyx-artical/SKILL.md`，按其工作流执行：
- 判断渠道（公众号 vs 视频号）
- 加载 `references/业务简介.md` + 对应子模块的 `任务说明书.md` + `风格参考库.md`
- 检索 `文案集.md` 最前部（避免重复、延续系列）

### 2. 解析任务参数

`$ARGUMENTS` 支持以下格式（按需拆分）：

```
[渠道] [文体] [主题]
```

| 参数 | 可选值 |
|---|---|
| **渠道** | 公众号 / 视频号 / 不指定（主动询问） |
| **文体** | 新闻纪实 / 实事评论 / 广告 / 节日祝福 / 科普体验（公众号）；招募 / 纪实 / 节日（视频号） |
| **主题** | 自由文本：研学团名 / 节日名 / 活动主题 / 需改写的原文 等 |

**示例**：
- `/ycyx-artical 公众号 新闻纪实 北流中学千人研学团来访`
- `/ycyx-artical 视频号 招募 寒假特别营`
- `/ycyx-artical 公众号 节日祝福 端午`
- `/ycyx-artical` （不指定参数 → 询问用户）

### 3. 生成草稿

按任务说明书的「交付物」一次性完整给出（不拆分多轮）：

| 渠道 | 交付物 |
|---|---|
| 公众号 | 主标题（≤22 字，可附副标题，1 主推 + 1 备选）+ 摘要（20~40 字）+ 正文 + 标签（2~5 个） |
| 视频号 | 短标题（≤30 字）+ 简介（60~120 字，三段式）+ 标签（恰好 15 个，首两个固定 `#玉柴 #研学`） |

### 4. 等待用户确认

将草稿一次性给出，等待用户回复「确认」或「修改建议」。

### 5. 写入文案库（用户确认后）

按对应子模块 `文案集.md` 头部的「条目格式说明」，将新条目插入**文档最前部**（日期倒序、最新在前），严格填写日期 / 系列 / 文体 / 标签等元数据。

## 核心硬性规则

- **不虚构**：课程、点位、人物、机构、数据以业务简介与文案集历史为准
- **职业生涯规划内容只面向高中学段**
- **不贩卖焦虑**；不用「最强大」「第一品牌」等绝对化违禁词
- **主体名称按用户当次指定自适应**
- **不擅自新增子栏目或改变交付格式**
- **只输出纯文本内容**：不产出配图提示词、封面/海报方案、IP 形象或其他美术内容

## 详细规则

完整规则、工作流、品牌资产速查见 `skills/ycyx-artical/SKILL.md` 与对应子模块 `references/任务说明书.md`。
