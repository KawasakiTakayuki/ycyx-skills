# 玉柴研学公众号文案写作任务说明书

> 本文件是「玉柴研学公众号文案」写作任务的**总要求**。AI 每次写作前必须通读，并同时参考《研学课程与业务简介.md（上级目录）》《玉柴研学公众号文案风格参考库.md》。
> 本文件只描述「写什么、怎么写、按什么标准验收」，业务与风格细节见另外两份文档。
> 本系统**只输出纯文本内容**，不涉及配图提示词、视觉方案或任何美术产出。

---

## 一、服务主体

- 主体名称：**玉柴研学文旅**
- 业务定位：依托玉柴集团（全球领先的发动机制造企业，始建于1951年）的工业资源，面向**中小学生、幼儿园、亲子家庭、企事业单位团体**开展研学旅行、工业科普与产教融合服务。
- 对外称呼可随用户要求自适应切换：玉柴研学、玉柴研学文旅、玉柴研学文旅公司、玉柴文旅等。

## 二、内容平台与发布场景

- 主发布平台：**微信公众号**（订阅号「玉柴研学」）。
- 平台特性决定了文案需具备：
  1. **标题即点击率**：订阅号列表页标题完整显示约 22 字以内，需有钩子（荣誉/数字/悬念/情绪/品牌前缀）。
  2. **中长文可读排版**：分段短（2~4 行）、小标题导航、关键词加粗、适度 emoji 分区，忌整段堆砌。
  3. **双向触达价值**：单篇同时承担「品牌形象」与「内容转化」——文末引导关注、预约报名、留言互动。
  4. **话题标签**：文末 2~5 个 `#标签`，见风格参考库「标签使用规律」。
  5. **体裁多元**：新闻纪实、实事评论、广告、节日祝福、科普体验等，按当次任务文体写作。

## 三、交付物（每次写作按需输出）

| 交付物 | 要求 |
|---|---|
| **文章标题** | 主标题 ≤22 字（最多不超过 28 字），可用品牌前缀「玉柴研学｜」；可附副标题。每次至少给出 1 个，建议给 2 个备选。 |
| **正文** | 符合文体结构（见风格参考库），段落短、有节奏；事实、人名、数字准确；结尾按文体含品牌落点/行动号召。 |
| **摘要/导语** | 订阅号摘要（一句话，约 20~40 字，提炼全文核心价值）。 |
| **文末标签** | 2~5 个 `#标签`，常含 `#玉柴研学`；节日/话题类内容贴传播词。 |

> 交付物**仅限以上文本**。本系统不提供配图提示词、插画说明、海报文案等美术类产出。

## 四、硬性规则（不可违反）

1. **不虚构**：课程、点位、人物、机构、数据以《研学课程与业务简介.md》和文案集历史内容为准；新闻纪实类必须写实。
2. **职业规划内容仅面向高中学段**；用户未明确指定时，一律不写职业规划内容。
3. **不用绝对化违禁词**（"最强大""第一品牌"等，引用官方表述除外）；教育内容不贩卖焦虑。
4. 主体名称按用户当次指定自适应；涉及具体人物须用准确姓名与职务（如总经理阚立超）。
5. 内容不得涉及敏感话题，符合主流宣传口径。
6. 广告类承诺（安全、证书、课程项目）须与真实课程一致，不夸大。

## 五、标准工作流程

1. **读取前置资料**：《玉柴研学公众号文案写作任务说明书.md》《研学课程与业务简介.md（上级目录）》《玉柴研学公众号文案风格参考库.md》。
2. **检索文案库**：读取《玉柴研学公众号文案集.md》最前部（条目按日期倒序、最新在前），确认近期文体、风格与已用标签（避免重复、保持系列连贯）。
3. **生成草稿**：一次性给出「标题 / 摘要 / 正文 / 标签」，等待用户确认或提出修改。
4. **确认定稿**：用户回复最终版本后，不得再改动文字。
5. **写入文案库**：按《玉柴研学公众号文案集.md》头部「条目格式说明」将新条目插入文档最前部（日期倒序、最新在前）。

## 六、写作质量自查清单

- [ ] 标题 ≤22 字（最长不超过 28 字），有钩子、无歧义
- [ ] 文体结构与风格参考库一致，段落短、可读性强
- [ ] 标签 2~5 个，含 `#玉柴研学`（适用时）
- [ ] 事实、人名、职务、数字准确无误；无错别字
- [ ] 教育类内容观点正向、不焦虑；职业规划仅限高中学段
- [ ] 新闻纪实类有明确时间/事件/地点；广告类含行动号召
- [ ] 输出仅含文本交付物，未附带任何配图/美术内容

## 七、通用禁忌

- 不用"最强大""第一品牌"等绝对化违禁词（历史文案中作为引用可保留原文）。
- 不堆砌辞藻、不用生僻词；不写与画面无关的空话。
- 不擅自新增子栏目、不改变交付格式。
- 节日祝福类不低俗媚俗；品牌露出克制，保持工业研学品牌调性。
